# JPR Bus Pass

College bus pass web app supporting Student, Alumni, and Parent roles.

**Live:** [https://bus-one-sigma.vercel.app](https://bus-one-sigma.vercel.app)

## Features

- Multi-role authentication (Student / Alumni / Parent)
- Bus pass management flows
- React + Vite modern stack

## Local Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Deployment

Linked to Vercel. Pushing to `main` triggers automatic deployment.
